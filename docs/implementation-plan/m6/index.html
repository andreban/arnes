Milestone 6 · Persistence

Sessions on disk

JSONL session logs, project-scoped storage, UUID v7-prefixed filenames, --continue / --resume CLI flags, and ACP session/load. After M6, every minute you spend with the agent is recoverable.

Why now

Through M5, every session you start dies when the process exits. M6 is the difference between a demo and a daily-driver tool. The format choice (append-only JSONL) doubles as the recipe for compaction (M7) and branching (deferred) without rewriting storage.

arnes-core::persist

// arnes-core/src/persist.rs

pub struct SessionWriter {
    fh: tokio::fs::File,
    path: PathBuf,
}

impl SessionWriter {
    pub async fn open(path: &Path, header: SessionHeader) -> io::Result<Self>;
    pub async fn append(&mut self, row: SessionRow) -> io::Result<()>;
    pub async fn close(self) -> io::Result<()>;
}

pub enum SessionRow {
    /// First line; written exactly once at open.
    Header(SessionHeader),
    /// Any user / assistant / tool_result message.
    Message {
        id:        Uuid,
        parent_id: Option<Uuid>,
        timestamp: u64,
        agent_id:  AgentId,       // V1: always Root; post-V1 sub-agents append here too
        message:   Message,
    },
    /// One row per turn carrying that turn's token counts + Option<Cost>.
    /// agent_id and ModelKey live on the inner Usage struct.
    Usage(UsageEntry),
    /// Recorded when compaction (M7) runs.
    Compaction(CompactionEntry),
    /// Reserved for post-V1 sub-agent lifecycle. V1 never writes these;
    /// the reader recognises them and treats them as no-ops.
    SubAgentStart { id: Uuid, parent_agent_id: AgentId, spec: SubAgentSpec },
    SubAgentEnd   { id: Uuid, agent_id: AgentId, /* result summary */ },
}

pub struct UsageEntry {
    pub id:        Uuid,
    pub timestamp: u64,
    pub usage:     Usage,         // from arnes-core::usage; carries agent_id + ModelKey
}

Two reader rules pinned to this format:

  • Unknown variant tags are not fatal. The reader matches on the variant tag; tags it doesn't recognise (a row from a newer arnes writing a variant V1 doesn't know yet) are logged and skipped. Forward compatibility on the wire so files written by a future arnes remain loadable.
  • Sub-agent rows are accepted but no-op at V1. SubAgentStart / SubAgentEnd rows could only appear in a file written by a post-V1 version; if seen, the V1 reader records the fact in diagnostics and continues.

On-disk layout

~/.arnes/sessions/
└── {project-hash}/                    # 8-char hash of cwd, no creation overhead
    ├── 0190f1c2-7d8a-summarize-the-readme.jsonl
    ├── 0190f25b-9c14-refactor-auth-middleware.jsonl
    └── ...
  • Project hash: first 8 chars of a stable hash (xxh3) of cwd.canonicalize(). No on-disk index of which project maps to which hash; the directory is the index, and you find a project's sessions by re-computing the hash from its cwd.
  • Filename: {uuid}-{slug}.jsonl. The UUID v7 is sortable (so ls -t orders by creation); the slug is a kebab-cased fragment of the first user message, max 60 chars.
  • Format: one JSON object per line. UTF-8. Final line not guaranteed newline-terminated — readers tolerate.

The writer

Open once at session start with the header; append a row per SessionEvent::TurnEnd (the entire turn worth of messages flushed atomically when the turn completes — we do not write partial assistant messages). Append a Header row only on initial open; resumed sessions reopen in append mode without rewriting the header. 

impl Session<F, E> {
    pub async fn prompt(&mut self, input: String) -> Result<()> {
        // ... existing logic ...
        // On TurnEnd:
        for msg in turn_messages {
            if let Some(w) = self.writer.as_mut() {
                w.append(SessionRow::Message {
                    id: Uuid::now_v7(),
                    parent_id: self.last_message_id,
                    timestamp: now_unix(),
                    message: msg,
                }).await?;
            }
        }
    }
}

The reader

pub async fn load_session(path: &Path) -> io::Result<LoadedSession> {
    let text = tokio::fs::read_to_string(path).await?;
    let mut header = None;
    let mut messages = Vec::new();
    let mut compactions = Vec::new();
    for (line_no, line) in text.lines().enumerate() {
        if line.is_empty() { continue; }
        match serde_json::from_str::<SessionRow>(line) {
            Ok(SessionRow::Header(h)) if line_no == 0 => header = Some(h),
            Ok(SessionRow::Header(_)) => { /* anomalous; log + skip */ }
            Ok(SessionRow::Message { message, .. }) => messages.push(message),
            Ok(SessionRow::Compaction(c)) => {
                // M7 affects how we reconstruct in-memory state.
                compactions.push(c);
            }
            Err(e) if line_no == text.lines().count() - 1 => {
                // Torn final line from a crash mid-write: tolerate, log.
            }
            Err(e) => return Err(io::Error::other(format!("bad row at line {line_no}: {e}"))),
        }
    }
    Ok(LoadedSession {
        header: header.ok_or_else(|| io::Error::other("missing header row"))?,
        messages, compactions,
    })
}

CLI flags

FlagBehaviour
arnes / arnes-acp (no resume flag) Fresh session. Mint a UUID v7, derive the project hash from cwd, open a new file.
--continue / -c Resume the most-recent session for the current project. ls the project's directory, sort by filename (UUID v7 is sortable), pick the newest.
--resume <id-or-prefix> Resume by UUID v7 prefix. Error if ambiguous.
--resume (no value) TUI: open an interactive picker (uses a ratatui table component). ACP: error — the editor should call session/load explicitly.
--no-persist Skip writer creation entirely. Useful for one-shot CI runs.

ACP: session/load

Until now we have responded to session/load with method not found. M6 implements it: take the session id, resolve to a file path, load, return the full content blocks so the client can rehydrate its view of the transcript. 

async fn handle_session_load(&self, params: SessionLoadParams) -> Result<SessionLoadResponse> {
    let path = self.resolve_session_path(params.session_id)?;
    let loaded = persist::load_session(&path).await?;
    let session = Session::resume(loaded, /* frontend, host, runner */).await?;
    self.sessions.insert(params.session_id, session);
    Ok(SessionLoadResponse {
        messages: loaded.messages.into_iter().map(to_acp_content).collect(),
        // ... mode, model, etc. ...
    })
}

Also advertise the loadSession capability in initialize's response now — previously omitted as unsupported.

Implementation tasks

  1. Create arnes-core::persist with SessionWriter, load_session, SessionRow, SessionHeader.
  2. Add uuid (with features = ["v7"]) and xxhash-rust as deps.
  3. Extend Session to take an optional SessionWriter; append on each TurnEnd.
  4. Add Session::resume(loaded, ...) constructor that rebuilds in-memory state from a LoadedSession.
  5. CLI: parse the new flags; implement project-hash + filename derivation; implement the most-recent and prefix-resolution helpers.
  6. TUI: implement the picker component (ratatui table); wire --resume (no arg) to launch it before the main session.
  7. ACP: implement handle_session_load; advertise loadSession capability in initialize.
  8. Title derivation helper: take first user message, kebab-case the first ~60 chars; sanitize for filename safety.

Testing checklist

  • Round-trip: write a session, close, load, assert messages match exactly.
  • Torn last line: append a half-written row; assert load returns the prior good state without erroring.
  • Header anomalies: missing header row; duplicate header row mid-file; assert sensible error or recovery.
  • Project hash stability: same cwd from two starts produces the same directory.
  • Resume prefix collision: two sessions sharing a 3-char prefix; --resume with that prefix errors with a useful message listing matches.
  • ACP load: golden transcript covering initialize, session/load, follow-up session/prompt; assert the loaded messages are returned and the prompt extends history correctly.

Risks specific to M6

  • Concurrent writes. One session per file; we never share. SessionRegistry in M8 will enforce this in-process. For now, two arnes instances pointed at the same file is undefined and unsupported — document it.
  • fsync cost. Default to OS buffering plus close-on-exit. Add an opt-in --fsync flag for users who want maximum durability at the cost of throughput.
  • Cross-platform paths. Project-hash must canonicalize paths so symlinks resolve consistently; dunce::canonicalize on Windows.
  • Format drift. The version field on the header lets us evolve. Bump on any breaking change; readers refuse versions higher than they understand.

End state of M6

Quit a session mid-task in either frontend. Restart. arnes -c (or session/load from your editor) picks up exactly where you were — same messages, same model, same skills, same JSONL log. The file on disk is plain text; you can cat it and read what happened.
