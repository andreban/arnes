feat/session-roundtrip-test

The acid test for phase 4: a deterministic two-turn integration test that runs Session::prompt twice against RecordingFrontend + InMemoryHost + ScriptedLlm, and asserts on every output channel — event sequence, history shape, cumulative usage.

Goal

One integration-test file, one #[tokio::test], that ties together every helper landed in this phase and validates that Session behaves end-to-end without an API key. Closes phase 4.

Files touched

  • new: crates/arnes-core/tests/session_roundtrip.rs — the integration test.

No source changes; no new deps.

Discussion

1. Why two turns and not one. A single-turn test was already written as PR #3's happy-path unit test. The integration test earns its name by exercising what one-turn doesn't:

  • History persistence across turns. Turn 2's prompt builds on turn 1's assistant message; the test asserts the history contains both turns' messages in order.
  • Cumulative usage actually cumulating. After two turns of two different scripted models, cumulative_usage() has two buckets and turns_total == 2.
  • Frontend sees a contiguous event stream. No spurious TurnStart or missing TurnEnd between turns; the recorded vec is a clean concatenation of turn-1 events then turn-2 events.

2. Test scenario: text-then-thinking-then-text. Turn 1's scripted LLM emits two text deltas, one thinking delta, one text delta, then stops. The assembled assistant message therefore has three ContentBlocks: a text block (concatenating the first two deltas), a thinking block, a text block. Turn 2 emits one text delta + stop — the simplest possible turn. This exercises the block-accumulator's "same-kind extends, different-kind opens" branch from PR #3, which a single all-text turn doesn't.

3. Token totals in the test. Each scripted stop carries a TokenCounts. After both turns the test asserts cumulative_usage().turns_total == 2 and that the per-model and per-agent projections each sum to the same total. The two turns use different ModelKeys so by_model() has two entries while by_agent() has one (both turns ran as AgentId::Root).

4. Event-sequence assertions. Two styles considered:

  • Full-equality assertion: assert_eq!(events, vec![...]) with every expected event spelled out. Pro: any mismatch fails clearly. Con: brittle to even cosmetic event-vocabulary changes; failures are long-diff.
  • Shape-and-count assertions (chosen): assert specific predicates — the recorded vec starts with TurnStart, contains two TurnEnds, contains exactly n TextDeltas with concatenated text equal to the script. Robust to non-essential changes; surfaces the structural invariants explicitly.

The shape-style assertions communicate intent ("the translator must emit one TurnEnd per turn") better than a literal-vec assertion ("here is every byte the translator produced"). Future-PR changes that add new event variants don't have to update an opaque vec.

5. Deterministic ordering. The test relies on ScriptedLlm being synchronous (no tokio::time::sleep) and on RecordingFrontend appending in the order on_event is called. The translator awaits each on_event before pulling the next delta from the stream, so the recorded vec's order matches the script's order exactly — no std::collections::HashSet-style "any order" assertions needed. If a future PR introduces concurrency between event emission and stream pulling (it shouldn't), this test will catch the reordering.

6. InMemoryHost is built but unused. The test wires up an InMemoryHost because Session::new requires a host arg, but the M1 translator doesn't call any host method (no tools yet). The host is constructed with InMemoryHost::new() — empty. M2's integration tests will seed it.

7. Cancellation is not exercised here. A cancellation test belongs in PR #3 (unit-test of the translator's cancel path) or a separate session_cancel.rs integration test. Bundling it into the round-trip test would obscure the happy-path assertion. Out of scope for this PR.

Code skeleton

// crates/arnes-core/tests/session_roundtrip.rs

mod support;

use std::sync::Arc;

use arnes_core::{
    AgentId, EventKind, ModelKey, Session, TokenCounts,
};

use support::{
    in_memory_host::InMemoryHost,
    recording_frontend::RecordingFrontend,
    scripted_llm::{ScriptedLlm, TurnScript, ScriptedDelta, ScriptedStop},
};

#[tokio::test]
async fn two_turn_roundtrip() {
    let frontend = Arc::new(RecordingFrontend::new());
    let host     = Arc::new(InMemoryHost::new());

    // Turn 1: two text deltas, one thinking, one text. Gemini model.
    // Turn 2: one text delta. Different model so by_model() has two rows.
    let llm = Arc::new(ScriptedLlm::new(vec![
        TurnScript {
            deltas: vec![
                ScriptedDelta::Text("Hello ".into()),
                ScriptedDelta::Text("world.".into()),
                ScriptedDelta::Thinking("(planning step)".into()),
                ScriptedDelta::Text(" Goodbye.".into()),
            ],
            stop: ScriptedStop {
                reason: /* end-of-turn */,
                tokens: TokenCounts { total: 15 },
                model:  ModelKey { provider: "gemini".into(), model_id: "g-2.5-flash".into() },
            },
        },
        TurnScript {
            deltas: vec![ScriptedDelta::Text("ack".into())],
            stop: ScriptedStop {
                reason: /* end-of-turn */,
                tokens: TokenCounts { total: 3 },
                model:  ModelKey { provider: "gemini".into(), model_id: "g-2.5-pro".into() },
            },
        },
    ]));

    let mut session = Session::new(
        frontend.clone(),
        host,
        llm,
        ModelKey { provider: "gemini".into(), model_id: "g-2.5-flash".into() },
    );

    session.prompt("hi").await.expect("turn 1 ok");
    session.prompt("ping").await.expect("turn 2 ok");

    let events = frontend.events();

    // Shape assertions:
    // - 2 TurnStart, 2 TurnEnd
    // - text deltas for turn 1 concatenate to "Hello world. Goodbye."
    // - one ThinkingDelta in between
    // - turn-2 events all follow turn-1 events
    // - TurnEnd[0].usage.tokens.total == 15; TurnEnd[1].usage.tokens.total == 3

    let cu = session.cumulative_usage();
    assert_eq!(cu.turns_total, 2);
    assert_eq!(cu.by_model().len(), 2);
    assert_eq!(cu.by_agent().len(), 1);

    // History shape:
    // - 4 entries: user, assistant, user, assistant
    // - assistant[0].content == [Text("Hello world."), Thinking("(planning step)"), Text(" Goodbye.")]
    // - assistant[1].content == [Text("ack")]
}

The history-shape assertion goes through a crate-private accessor added in this PR for the test's sake — or, equivalently, a #[cfg(test)] getter on Session. The choice between those two is the only meaningful one in this PR's implementation; bias toward the #[cfg(test)] getter because it's strictly internal and doesn't leak into the public surface.
