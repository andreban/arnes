feat/cumulative-usage

The aggregation primitive: a HashMap<(AgentId, ModelKey), ModelUsage> with a record() method that folds a TurnUsage into the matching bucket.

Goal

Ship CumulativeUsage with record(). The derived views (by_model / by_agent) land in PR #3.

Files touched

  • new: crates/arnes-core/src/metering/cumulative_usage.rs.
  • modify: crates/arnes-core/src/metering/mod.rs + crates/arnes-core/src/lib.rs — module + re-exports.

No new deps. (std::collections::HashMap is in std.)

Discussion

1. Indexing by (AgentId, ModelKey). Already established in core.html's future-compat table: one bucket per (agent, model) pair. V1 only ever populates (AgentId::Root, model) entries (one or two if a session switches models mid-run); post-V1 sub-agents and sub-agent model choices each get their own bucket additively. The hash-map keying is why we derived Hash on AgentId and ModelKey in phase 2.

2. record() semantics. Fold one TurnUsage into the bucket identified by (usage.agent_id, usage.model), creating the bucket if it doesn't yet exist:

  • bucket.tokens += usage.tokens (via TokenCounts's AddAssign).
  • Increment bucket.turns by 1.
  • Increment turns_total on the outer struct by 1.

3. Outer turns_total as a public field. Maintained by record(); exposed because frontends want "total turns this session" without summing per-bucket. Could equally be a method that sums; the field is cheaper and the value is trivially derivable so the duplication risk is low.

Code skeleton

// crates/arnes-core/src/metering/cumulative_usage.rs

use std::collections::HashMap;

use crate::{AgentId, ModelKey, ModelUsage, TokenCounts, TurnUsage};

/// All token totals for one session, bucketed by (agent, model).
#[derive(Clone, Debug, Default)]
pub struct CumulativeUsage {
    by_agent_and_model: HashMap<(AgentId, ModelKey), ModelUsage>,
    pub turns_total: u32,
}

impl CumulativeUsage {
    /// Fold one turn's `TurnUsage` into the matching bucket.
    pub fn record(&mut self, u: TurnUsage) {
        let key = (u.agent_id.clone(), u.model.clone());
        let bucket = self
            .by_agent_and_model
            .entry(key)
            .or_insert_with(|| ModelUsage {
                model: u.model.clone(),
                tokens: TokenCounts::default(),
                turns: 0,
            });

        bucket.tokens += u.tokens;
        bucket.turns += 1;

        self.turns_total += 1;
    }
}

Tests

  • Empty default: CumulativeUsage::default() has zero turns_total.
  • One bucket: record one TurnUsage; turns_total == 1; the bucket holds the input tokens.
  • Two buckets (per-(agent, model) bucketing): record two TurnUsages with different ModelKeys; the internal map has two entries.
  • Same-bucket aggregation: record three TurnUsages with the same (agent, model); the bucket's turns == 3 and tokens sum.
