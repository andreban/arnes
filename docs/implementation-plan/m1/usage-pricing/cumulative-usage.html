feat/cumulative-usage

The aggregation primitive: a HashMap<(AgentId, ModelKey), ModelUsage> with a record() method that folds a Usage into the matching bucket.

Goal

Ship CumulativeUsage with record(), total_known_cost(), and total_turns_with_unknown_cost(). The derived views (by_model / by_agent) land in PR #7.

Files touched

  • modify: crates/arnes-core/src/usage.rs — append CumulativeUsage.
  • modify: crates/arnes-core/src/lib.rs — re-export.

No new deps. (std::collections::HashMap is in std.)

Discussion

1. Indexing by (AgentId, ModelKey). Already established in core.html's future-compat table: one bucket per (agent, model) pair. V1 only ever populates (AgentId::Root, model) entries (one or two if a session switches models mid-run); post-V1 sub-agents and sub-agent model choices each get their own bucket additively. The hash-map keying is why we derived Hash on AgentId and ModelKey in phase 2.

2. record() semantics. Fold one Usage into the bucket identified by (usage.agent_id, usage.model), creating the bucket if it doesn't yet exist. Field-by-field:

  • Add each *_tokens count to the bucket's matching field.
  • Increment turns by 1.
  • Increment turns_total on the outer struct by 1.
  • If usage.cost is Some(c): bucket.known_cost += c.
  • If usage.cost is None: bucket.turns_with_unknown_cost += 1.

Note that both bucket-level counters update for every turn: turns increments unconditionally; known_cost or turns_with_unknown_cost increments depending on whether cost was known. So turns == known_cost_turn_count + turns_with_unknown_cost is an invariant. (Where known_cost_turn_count is what isn't stored but is derivable.)

3. Separating known_cost from turns_with_unknown_cost. The alternative would be to coerce unknown-cost turns to Cost::default() and add them to known_cost. We don't, because this is the cross-cutting "Unknown is never silently zero" decision in action: the consumer needs to be able to render "5 unknown-cost turns" separately from "$0.123 across 47 known-cost turns."

4. total_known_cost() implementation. Sum every bucket's known_cost. Linear in the number of buckets (typically 1–2 at V1; bounded by the small number of distinct (agent, model) pairs ever seen). No caching — the consumer can cache the result if they care.

5. Outer turns_total as a public field. Maintained by record(); exposed because frontends want "total turns this session" without summing per-bucket. Could equally be a method (turns_total()) that sums; the field is cheaper and the value is trivially-derivable so the duplication risk is low.

Code skeleton

// Appended to crates/arnes-core/src/usage.rs:

use std::collections::HashMap;

/// All token + cost totals for one session, bucketed by (agent, model).
#[derive(Clone, Debug, Default)]
pub struct CumulativeUsage {
    by_agent_and_model: HashMap<(AgentId, ModelKey), ModelUsage>,
    pub turns_total: u32,
}

impl CumulativeUsage {
    /// Fold one turn's `Usage` into the matching bucket.
    pub fn record(&mut self, u: Usage) {
        let key = (u.agent_id.clone(), u.model.clone());
        let bucket = self
            .by_agent_and_model
            .entry(key)
            .or_insert_with(|| ModelUsage {
                model: u.model.clone(),
                input_tokens: 0,
                output_tokens: 0,
                cache_read_tokens: 0,
                cache_write_tokens: 0,
                thinking_tokens: 0,
                turns: 0,
                known_cost: Cost::default(),
                turns_with_unknown_cost: 0,
            });

        bucket.input_tokens       += u.input_tokens;
        bucket.output_tokens      += u.output_tokens;
        bucket.cache_read_tokens  += u.cache_read_tokens;
        bucket.cache_write_tokens += u.cache_write_tokens;
        bucket.thinking_tokens    += u.thinking_tokens;
        bucket.turns              += 1;

        match u.cost {
            Some(c) => bucket.known_cost += c,
            None    => bucket.turns_with_unknown_cost += 1,
        }

        self.turns_total += 1;
    }

    /// Sum of `known_cost` across every bucket.
    pub fn total_known_cost(&self) -> Cost {
        let mut total = Cost::default();
        for bucket in self.by_agent_and_model.values() {
            total += bucket.known_cost;
        }
        total
    }

    /// Total count of turns whose cost was `None` (model pricing Unknown).
    pub fn total_turns_with_unknown_cost(&self) -> u32 {
        self.by_agent_and_model
            .values()
            .map(|b| b.turns_with_unknown_cost)
            .sum()
    }
}

Tests

  • Empty default: CumulativeUsage::default() has zero turns_total and empty totals.
  • One bucket: record one Usage; turns_total == 1; total_known_cost equals the input cost.
  • Two buckets (per-(agent, model) bucketing): record two Usages with different ModelKeys; the internal map has two entries; total_known_cost is the sum.
  • Unknown-cost counting: record one Usage with cost: Some(...) and one with cost: None; total_known_cost only includes the priced one; total_turns_with_unknown_cost == 1.
  • Invariant: for every bucket, turns == (turns_with_known_cost) + turns_with_unknown_cost (derived in the test).
