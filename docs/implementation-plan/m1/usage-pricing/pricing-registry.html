feat/pricing-registry

PricingRegistry — in-memory lookup of ModelCostInfo by (provider, model_id), with wildcard patterns and a user-override-wins merge rule. The actual TOML file loading lands in PR #6; this PR ships the registry structure + lookup + the compute_cost helper.

Goal

Ship the data structure callers consult to turn a ModelKey + raw token counts into a ModelCostInfo (and from there, an Option<Cost>). Construction takes pre-parsed rules; the TOML parser that produces those rules lands in PR #6.

Files touched

  • new: crates/arnes-core/src/pricing.rs — PricingRegistry, lookup, compute_cost helper.
  • modify: crates/arnes-core/src/lib.rs — module + re-exports.

No new deps.

Discussion

1. Internal rule shape. Each pricing entry has a provider, either an exact model_id or a wildcard pattern, and a ModelCostInfo. The natural internal representation: 

struct Rule {
    provider: String,
    matcher:  Matcher,
    info:     ModelCostInfo,
}

enum Matcher {
    Exact(String),  // matches a single model_id
    Pattern(String), // glob-style: only "*" for full wildcard at M1
}

M1 only needs the trivial wildcard case (the bundled Ollama rule: provider = "ollama", pattern = "*", info = Free). We ship a minimal Matcher that handles exact matches and "*"; more sophisticated patterns (prefix wildcards like "gemini-2.5-*") can be added when a provider needs them.

2. Lookup precedence. Exact matches always beat patterns. Within those tiers, the order rules were inserted matters only for the merge step (user overrides bundled), not for matching semantics. Concretely:

  1. If any rule has provider == key.provider and Matcher::Exact(model_id) == key.model_id: return that rule's info.
  2. Else if any rule has provider == key.provider and Matcher::Pattern("*"): return that rule's info.
  3. Else: return ModelCostInfo::Unknown.

3. Bundled-vs-user merge. User overrides win. The construction API takes two rule sets: 

pub fn from_rules(bundled: Vec<Rule>, user: Vec<Rule>) -> Self;

Internal merge: walk user first, then bundled. Inserting a rule for (provider, exact-id) displaces any prior rule for the same (provider, exact-id). Same for (provider, "*") patterns. User entries written first means bundled entries can't displace them.

PR #6's loader produces the two Vec<Rule>s; this PR ships the registry that consumes them and accepts test-only construction with rules built directly.

4. compute_cost helper. Lives next to the registry because it's the bridge from raw tokens + pricing to Option<Cost>. The math is straightforward integer arithmetic: per token kind, (tokens * micros_per_mtok) / 1_000_000. For optional rates (cache_read_per_mtok etc.), fall back to the matching base rate (input_per_mtok for cache, output_per_mtok for thinking). Mapping the three-state ModelCostInfo:

  • Priced(p) → Some(cost) with values computed from p.
  • Free → Some(Cost::default()).
  • Unknown → None.

Callers (phase 4's Session at turn end) do let cost = compute_cost(&registry.lookup(&model), tokens); — one call.

5. Where is the registry constructed? Not in M1's ToolContext or per-tool scope; it lives session-wide. Phase 4 builds one PricingRegistry at Session::new and shares it for the session's lifetime. M1's registry struct doesn't need to be Sync-by-default since it's immutable post-load (we'd reach for Arc<PricingRegistry> at the call sites if shared), but the type derives Clone for flexibility.

//! Pricing registry: lookup of `ModelCostInfo` by `(provider, model_id)`.

use crate::{Cost, Micros, ModelCostInfo, ModelKey, ModelPricing};

#[derive(Clone, Debug)]
pub struct Rule {
    pub provider: String,
    pub matcher:  Matcher,
    pub info:     ModelCostInfo,
}

#[derive(Clone, Debug)]
pub enum Matcher {
    Exact(String),
    Pattern(String),  // "*" only at M1
}

#[derive(Clone, Debug, Default)]
pub struct PricingRegistry {
    rules: Vec<Rule>,
}

impl PricingRegistry {
    /// Build a registry from bundled and user-override rule sets.
    /// User entries take precedence over bundled entries for the same
    /// `(provider, matcher)`.
    pub fn from_rules(bundled: Vec<Rule>, user: Vec<Rule>) -> Self {
        let mut rules = Vec::with_capacity(user.len() + bundled.len());
        rules.extend(user);
        for b in bundled {
            let already_present = rules.iter().any(|r| {
                r.provider == b.provider && same_matcher(&r.matcher, &b.matcher)
            });
            if !already_present {
                rules.push(b);
            }
        }
        PricingRegistry { rules }
    }

    /// Look up the cost info for a `ModelKey`.
    /// Exact matches beat patterns; unmatched models return `Unknown`.
    pub fn lookup(&self, key: &ModelKey) -> ModelCostInfo {
        for r in &self.rules {
            if r.provider == key.provider {
                if let Matcher::Exact(id) = &r.matcher {
                    if id == &key.model_id {
                        return r.info.clone();
                    }
                }
            }
        }
        for r in &self.rules {
            if r.provider == key.provider {
                if let Matcher::Pattern(p) = &r.matcher {
                    if p == "*" {
                        return r.info.clone();
                    }
                }
            }
        }
        ModelCostInfo::Unknown
    }
}

fn same_matcher(a: &Matcher, b: &Matcher) -> bool {
    match (a, b) {
        (Matcher::Exact(x), Matcher::Exact(y))     => x == y,
        (Matcher::Pattern(x), Matcher::Pattern(y)) => x == y,
        _ => false,
    }
}

/// Compute the cost for a turn given the model's `ModelCostInfo` and raw
/// token counts. Returns `None` for `Unknown`.
pub fn compute_cost(info: &ModelCostInfo, tokens: &TokenCounts) -> Option<Cost> {
    match info {
        ModelCostInfo::Unknown => None,
        ModelCostInfo::Free    => Some(Cost::default()),
        ModelCostInfo::Priced(p) => Some(price(p, tokens)),
    }
}

fn price(p: &ModelPricing, t: &TokenCounts) -> Cost {
    let input       = mul(t.input,       p.input_per_mtok);
    let output      = mul(t.output,      p.output_per_mtok);
    let cache_read  = mul(t.cache_read,  p.cache_read_per_mtok.unwrap_or(p.input_per_mtok));
    let cache_write = mul(t.cache_write, p.cache_write_per_mtok.unwrap_or(p.input_per_mtok));
    let thinking    = mul(t.thinking,    p.thinking_per_mtok.unwrap_or(p.output_per_mtok));
    let total       = input + output + cache_read + cache_write + thinking;
    Cost { input, output, cache_read, cache_write, thinking, total }
}

fn mul(tokens: u64, per_mtok: Micros) -> Micros {
    // Integer math: (tokens * micros_per_mtok) / 1_000_000.
    // Use i128 intermediate to avoid overflow at large token counts.
    let product = (tokens as i128) * (per_mtok.0 as i128);
    Micros((product / 1_000_000) as i64)
}

pub struct TokenCounts {
    pub input:       u64,
    pub output:      u64,
    pub cache_read:  u64,
    pub cache_write: u64,
    pub thinking:    u64,
}

Tests

  • Exact match: rule for ("gemini", "gemini-2.5-flash") matches that exact key; doesn't match ("gemini", "gemini-2.5-pro").
  • Wildcard match: rule for ("ollama", "*", Free) matches every ollama model_id.
  • Exact beats wildcard: if both a ("provider", "exact-id") and a ("provider", "*") rule exist, the exact one wins.
  • Unmatched returns Unknown: looking up a provider/model with no rules returns ModelCostInfo::Unknown.
  • User overrides bundled: bundled rule says Free; user override for the same exact key says Priced; lookup returns Priced.
  • compute_cost three-state: Priced returns Some with computed amounts; Free returns Some(Cost::default()); Unknown returns None.
  • compute_cost optional fallback: a ModelPricing with cache_read_per_mtok = None falls back to input_per_mtok.
  • Arithmetic: 75 micros/Mtok × 1,000,000 tokens = Micros(75) (a.k.a. $0.000075).
