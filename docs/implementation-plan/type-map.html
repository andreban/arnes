Where to start reading

  • Frontend — what every UI adapter implements; it receives SessionEvents and answers permission prompts. Session drives it.
  • Host — what tools call instead of touching the OS; LocalHost is the default in-process impl.
  • Session<F, H> — the orchestrator. Owns the system prompt, the tool registry, the persistence writer, the compactor, and the cumulative usage; its prompt() method is the single hot path.
  • Tool + ToolContext — every tool runs against the bundled context so adding a future capability (e.g. timing budget) doesn't break the trait signature.
  • AgentId — threaded through events, tool contexts, usage, and JSONL rows. V1 only ever creates Root; the field is there so sub-agents can land post-V1 without a breaking change.
